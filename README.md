# ☕ Java Básico — Programação Orientada a Objetos (Parte 4)

Repositório com as resoluções dos **10 primeiros exercícios** da apostila *Java Básico - Parte 4: Programação Orientada a Objetos em Java*, desenvolvidos no **IntelliJ IDEA**[cite: 42, 78]. O objetivo desta etapa é aplicar os conceitos fundamentais de modelagem de classes, instanciação de objetos, comportamento, construtores, uso da palavra-chave `this` e tipos `enum`[cite: 42, 78].

## 📋 Exercícios Resolvidos

| Exercício | Classe / Tipo | Descrição |
| :--- | :--- | :--- |
| `01` | `Pessoa` | Criação de classe com atributos (`nome`, `idade`), instanciação de dois objetos e exibição de dados. |
| `02` | `Produto` | Instanciação de três objetos (`nome`, `preco`) e lógica para identificar o item mais caro. |
| `03` | `Retangulo` | Modelagem com atributos `largura` e `altura` e implementação do método `area()`. |
| `04` | `Conta` | Gerenciamento de estado (`saldo`) por meio do método de instância `depositar(double)`. |
| `05` | `Lampada` | Controle de estado booleano (`ligada`) com os métodos `ligar()` e `desligar()`. |
| `06` | `Aluno` | Armazenamento de duas notas e cálculo de média através do método `calcularMedia()`. |
| `07` | `Livro` | Controle de disponibilidade com os métodos `emprestar()` e `devolver()`. |
| `08` | `Curso` | Inicialização de objeto via construtor parametrizado (`nome` e `cargaHoraria`). |
| `09` | `Celular` | Uso explícito da referência `this` no construtor para diferenciar atributos (`marca`, `modelo`) de parâmetros. |
| `10` | `Turno` (`enum`) | Definição de constantes (`MANHA`, `TARDE`, `NOITE`) e iteração com `values()`. |
